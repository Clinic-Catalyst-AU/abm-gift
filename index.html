Download the skills pack
  1. Download the pack and double click it. Inside are a start-here note and four small zip files. Leave those four zipped.
  2. Open Claude (the desktop app or claude.ai). Click your initials, then Settings, then Capabilities, and make sure Code execution and file creation is on.
  3. Go to Customize, then Skills. Click +, then Create skill, then Upload a skill, and pick the first zip.
  4. Repeat for the other three zips. Check each one is toggled on.
  5. Start a new chat and type run the clinic voice foundation skill. Claude takes it from there.
Run them in this order the first time. Set aside about thirty minutes. After that it is a couple of minutes whenever you need content.
  • Clinic Voice Foundation - Claude reads how you already write, then writes your voice down so nothing it produces sounds like every other clinic.
  • Clinic Brand Guide - the one file you paste into Claude so every caption, email and page sounds like you.
  • Clinic Hook Generator - type a topic, get five scroll-stopping hooks in your voice, screened against AHPRA.
  • Bonus: Clinic Video Script - say what the video is about and get what to say, what to film and what goes on screen.
